# @akin2unde/flowui-react

Tailwind-styled FlowUI components for React. FlowUI ships compiled CSS, so the
host application does not need Tailwind.

```bash
npm install @akin2unde/flowui-react @fortawesome/fontawesome-free
```

```tsx
import "@akin2unde/flowui-react/styles.css";
import { Button, FlowUIProvider } from "@akin2unde/flowui-react";
```

See the [FlowUI repository](https://github.com/akin2unde/FlowUI) for the full
component gallery and API documentation.
